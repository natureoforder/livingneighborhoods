## The baseline code

On this website, we have provided a baseline system of unfoldings. These deal with very fundamental matters, such as land, diagnosis, topography, relationship to adjacent buildings, relations of building volumes to outdoor space, internal layout, room shape, stairs, windows, doors, ornament, and many construction details and procedures.

## Choose unfoldings from the baseline code

Most of these baseline unfoldings are practical, and useful, and true, in a great variety of different places on earth, in cities and in small towns, and in a variety of cultures and traditions -- even though they will undoubtedly need modification or some local variant to make sure the generic version fits and is useful in the local context.
